# مسودة التحديث القادم — Private Diary

**الحالة:** مسودة داخلية فقط؛ لم تُرسل إلى Google Play.

## النطاق المقترح

هذا التحديث مخصص لتحسين حضور المتجر المحلي، وليس لإضافة وظائف جديدة إلى التطبيق. يتضمن تجهيز أصول لقطات محرر المذكرات بالعربية والفرنسية، مع إبقاء الإصدار الحالي كما هو إلى أن يقرر المالك إرسال التغييرات. لا ينبغي رفع إصدار AAB جديد لهذا النطاق وحده ما لم تُضاف تغييرات فعلية إلى كود التطبيق.

| العنصر | القرار |
|---|---|
| رقم الإصدار | يُحدد فقط إذا أُضيف كود أو أُنشئ AAB جديد |
| نطاق التغيير | أصول قائمة المتجر العربية والفرنسية |
| لقطات جديدة | `03-editor-ar.png` و`03-editor-fr.png` محفوظتان في المشروع |
| حالة الإرسال | غير مرسلة |
| Managed publishing | متوقف؛ النشر التلقائي مفعّل |
| التحقق المطلوب | مراجعة الأصول ثم إرسالها فقط بعد موافقة المالك |
